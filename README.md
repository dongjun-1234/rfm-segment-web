# 📊 RFM 세그먼트 분석기

고객 CSV를 올리면 **데이터 품질 점검 → R·F·M 컬럼 지정 → 분석 목표(가중치) 선택 → 고객 세그먼트**까지 한 화면에서 보여주는 Streamlit 웹앱입니다.

🔗 **웹에서 바로 써보기:** [rfm-segment-web.streamlit.app](https://rfm-segment-web-j25wmxqn5dapph6pt6lqmnx.streamlit.app/)

## 만든 이유

대형 마트 고객 데이터로 RFM 분석 실습을 하면서 두 가지가 아쉬웠습니다.

1. 기준(가중치, 이상값 처리)을 바꿀 때마다 같은 코드를 처음부터 다시 돌려야 했다.
2. 데이터마다 컬럼 이름과 형태가 달라, 다른 데이터에는 그대로 쓸 수 없었다.

그래서 **어떤 CSV든 올리면 같은 절차로 분석하고, 기준을 바꾸면 결과가 바로 바뀌는 도구**로 다시 만들었습니다.

## 주요 기능

| 단계 | 내용 |
|---|---|
| 데이터 품질 점검 | 결측값·중복 행·값이 하나뿐인 컬럼·극단값을 찾아 보여주고, 처리 여부는 사용자가 직접 선택 |
| 두 가지 CSV 형태 지원 | **고객 합산형**(고객 1명 = 1줄)과 **거래형**(거래 1건 = 1줄, 앱이 R·F·M을 직접 계산) |
| 컬럼 자동 추정 | 컬럼 이름을 보고 고객 ID·최근성·빈도·금액 후보를 미리 골라 둠 (수정 가능, 새 파일을 올리면 다시 추정) |
| 결측 처리 기준 | R·F·M에 쓰는 컬럼이 비면 그 고객만 제외(20% 이상이면 경고). 소득 같은 다른 컬럼은 고객을 빼지 않고 특성 비교에서만 빈 값 제외 |
| 분석 목표 프리셋 | 균형 1:1 · 재구매 중시 3:1 · 매출 중시 1:3 · 직접 조정. 바꾸면 세그먼트가 실제로 바뀌고 균형 대비 몇 명이 바뀌었는지 표시 |
| 세그먼트 두 축 구조 | 상태(R 점수) × 가치(V = F·M 가중 평균)로 VIP·충성·이탈 위험 우수·잠재 성장·일반·휴면 6개 그룹 |
| 고객 특성 비교 | 소득·자녀 수·나이 등을 **전체 대비 차이(%)** 로 비교. 요약표는 높으면 파랑, 낮으면 주황 |
| 처리 기록 | 데이터·컬럼 지정·데이터 정리·세그먼트 기준·특성 비교 설정을 기록하고 **.md 파일로 내려받기**, 결과는 CSV로 |

## 분석 방법

- **점수화**: R·F·M을 각각 순위 기준으로 5등분해 1~5점 (R은 최근일수록 높은 점수). 동점이 많아도 구간이 고르게 나뉘도록 순위를 사용했습니다.
- **두 축으로 세그먼트 나누기**
  - **상태 축 = R 점수**: 고객이 지금 오고 있는지. 가중치를 주지 않습니다.
  - **가치 축 = V = (wF·F + wM·M) / (wF + wM)**: 구매 횟수와 금액 점수의 가중 평균. 가중치는 여기에만 쓰입니다.
- **분석 목표 프리셋**: 균형 F:M = 1:1(기본), 재구매 중시 3:1, 매출 중시 1:3, 또는 직접 조정. 가중치를 바꾸면 세그먼트가 실제로 바뀌고, 균형(1:1) 대비 몇 명이 바뀌었는지 보여줍니다.
- R에 가중치를 주지 않는 이유: R을 키우면 '최근에 온 고객'이 위로 올라올 뿐, 이탈 고객을 찾는 데 도움이 되지 않습니다. 이탈 방지가 목적이면 '이탈 위험 우수고객' 세그먼트를 봅니다.

**세그먼트 규칙**

| 세그먼트 | 조건 |
|---|---|
| VIP | V ≥ 4 그리고 R ≥ 4 |
| 충성 고객 | V ≥ 4 그리고 R = 3 |
| 이탈 위험 우수고객 | V ≥ 4 그리고 R ≤ 2 |
| 잠재 성장 | V ≤ 2 그리고 R ≥ 4 |
| 휴면 | V ≤ 2 그리고 R ≤ 2 |
| 일반 | 위에 해당하지 않음 |

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 파일 구성

```
app.py          # 웹 화면 (Streamlit)
rfm_core.py     # 분석 로직 (불러오기, 품질 점검, 점수화, 세그먼트)
requirements.txt
```

## 데이터 안내

분석에 사용한 실습 데이터는 저작권 문제로 저장소에 포함하지 않았습니다. 체험용 샘플 데이터는 추후 추가 예정입니다.

## 앞으로 추가할 기능

- 기간별 세그먼트 이동 추적 (예: VIP → 이탈 위험)
- AI가 컬럼 매핑과 세그먼트별 마케팅 전략 초안을 제안하고, 사용자가 데이터로 검증하는 기능
