# 📊 RFM 세그먼트 분석기

고객 CSV를 올리면 **데이터 품질 점검 → R·F·M 컬럼 지정 → 가중치 조절 → 고객 세그먼트**까지 한 화면에서 보여주는 Streamlit 웹앱입니다.

🔗 **웹에서 바로 써보기:** ((https://rfm-segment-web-j25wmxqn5dapph6pt6lqmnx.streamlit.app/))

## 만든 이유

대형 마트 고객 데이터로 RFM 분석 실습을 하면서 두 가지가 아쉬웠습니다.

1. 기준(가중치, 이상값 처리)을 바꿀 때마다 같은 코드를 처음부터 다시 돌려야 했다.
2. 데이터마다 컬럼 이름과 형태가 달라, 다른 데이터에는 그대로 쓸 수 없었다.

그래서 **어떤 CSV든 올리면 같은 절차로 분석하고, 기준을 바꾸면 결과가 바로 바뀌는 도구**로 다시 만들었습니다.

## 주요 기능

| 단계 | 내용 |
|---|---|
| 데이터 품질 점검 | 결측값·중복 행·값이 하나뿐인 컬럼·극단값을 찾아 보여주고, 처리 여부는 사용자가 직접 선택 |
| 두 가지 CSV 형태 지원 | **고객 합산형**(고객 1명 = 1줄)과 **거래형**(거래 1건 = 1줄, 앱이 R·F·M을 직접 계산) |
| 컬럼 자동 추정 | 컬럼 이름을 보고 고객 ID·최근성·빈도·금액 후보를 미리 골라 둠 (수정 가능) |
| 가중치 조절 | R·F·M 슬라이더로 중요도를 바꾸면, 가중치를 같게 뒀을 때보다 **상위 20% 고객이 몇 명 바뀌는지** 표시 |
| 세그먼트 결과 | VIP·충성·이탈 위험 우수·잠재 성장·일반·휴면 6개 그룹의 고객 비중과 매출 비중 |
| 고객 특성 비교 | 소득, 자녀 수, 품목별 구매 구성 등을 세그먼트별로 비교 |
| 처리 기록 | 어떤 데이터를 왜 제외했는지 기록을 남기고, 결과를 CSV로 내려받기 |

## 분석 방법

- **점수화**: R·F·M을 각각 순위 기준으로 5등분해 1~5점 (R은 최근일수록 높은 점수). 동점이 많아도 구간이 고르게 나뉘도록 순위를 사용했습니다.
- **가치 등급**: 가중 점수 = (wR·R + wF·F + wM·M) / (wR + wF + wM) → 상위 20% / 20~50% / 50~80% / 하위 20%
- **세그먼트 규칙** (가중치와 무관하게 R·F·M 점수 조합으로 결정)

| 세그먼트 | 조건 |
|---|---|
| VIP | R, F, M 모두 4점 이상 |
| 충성 고객 | R 3점 이상, F·M 평균 4점 이상 |
| 이탈 위험 우수고객 | R 2점 이하, F·M 평균 4점 이상 |
| 잠재 성장 | R 4점 이상, F·M 평균 2.5점 이하 |
| 휴면 | R 2점 이하, F·M 평균 2점 이하 |
| 일반 | 위에 해당하지 않음 |

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 파일 구성

```
app.py          # 웹 화면 (Streamlit)
rfm_core.py     # 분석 로직 (불러오기, 품질 점검, 점수화, 세그먼트)
requirements.txt
```

## 데이터 안내

분석에 사용한 실습 데이터는 저작권 문제로 저장소에 포함하지 않았습니다. 체험용 샘플 데이터는 추후 추가 예정입니다.

## 앞으로 추가할 기능
